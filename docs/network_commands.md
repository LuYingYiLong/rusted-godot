# 原版联机命令接入

原版服务器通过 10 号包发送下一同步帧边界及该边界上的命令。普通战斗帧没有逐单位的位置、生命值、护盾或高度快照。客户端必须从地图初始单位开始，按相同顺序执行命令和模拟单位行为

`RwBattleCommandReader` 保留命令的目标单位、集结点、攻击模式、排队标志、共享控制位、系统步长以及 `CommandTarget` 的逐单位目标和压缩路径。`RwBattleTimeline` 只在地图完成加载后推进，并在边界帧交付命令。`RwUnitOrderController` 执行移动、追击、排队和目标导航；地图继续处理建造、生产、集结点与资源消费

服务器的完整队伍更新若在战斗中携带资金余额，`RwVanillaEconomy` 会用该值修正本地预测；局部队伍更新只包含连接状态，不覆盖资金

弹体和单位共用原版对象 ID 序列。战斗地图在弹体产生和建筑实际创建时推进计数器；建造失败时不消耗 ID

目前战斗模拟还没有覆盖所有原版单位、武器、维修、回收、运输和 AI 行为，也没有解码 35 号重新同步存档。收到该存档时暂停本地时间线并报告状态，避免继续显示已知失配的模拟。要达到原版房间的长期逐帧一致性，仍需补齐这些行为与存档恢复，再用真实房间的抓包和校验和验证
