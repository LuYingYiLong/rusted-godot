# 原版 1.15 与 Rusted Godot 特性差异

本表以本机原版 `game-lib.jar` 和 `rw_analysis-master` 的 `02b-decompiled` 为 1.15 依据。原版 jar 的 SHA-256 为 `8a550a37e2d8a5430866090d4e7d5892f9010b47f52a5a09350fc66c620deec9`，与源码项目的 stock 指纹一致。`03-deobfuscated` 类名可能误导，例如其中的 `MovementController` 实际是弹体类，涉及公式时应回看 `02b-decompiled`

| 特性 | 原版 1.15 依据 | Rusted Godot 现状 | 判定 |
| --- | --- | --- | --- |

## 自动测试

在 Godot 项目根目录运行：

```powershell
.\tools\run_rw_115_reference_tests.ps1
```

脚本读取下载目录的 1.15 源码和本机原版 jar，运行二进制枚举探针及 Godot 回归检查，并在临时报告目录写入 `summary.json`、stdout 和 stderr 日志。可以用 `-SourceRoot`、`-GameJar`、`-JavaExecutable`、`-GodotExecutable` 和 `-ReportDirectory` 指向别的安装位置。`evidence` 字段区分原版二进制、原版样本、合成协议样本和本地回归；本地回归通过只说明现有功能未退化
